# praTexEditOR: UX ekran po ekranie

Wygląd: tokeny praSzczur (`design/ui-tokens.md`). Ikony: ręcznie pisane inline SVG
(`Icon.svelte`, `stroke="currentColor"`), bez emoji. Na szkicach `[▤]` itp. oznacza ikonę, nie tekst.

---

## 1. Zasady

1. **Ikona + tooltip.** Każdy przycisk to piktogram. Tooltip (po 400 ms) pokazuje nazwę i aktualny
   skrót, np. `Pogrubienie  ⌘B`. Tekst w UI tylko tam, gdzie jest treścią (nazwy plików,
   komunikaty błędów).
2. **Wszystko da się przeciągnąć.** Pliki w drzewie, pliki z Findera, obrazy do edytora,
   zrzuty ze schowka. Cel upuszczenia zawsze świeci akcentem, zanim się puści.
3. **Każda akcja daje widoczny skutek.** Pigułka statusu kompilacji, krótkie podświetlenie
   miejsca SyncTeX, animacja pojawienia się nowego pliku w drzewie, toast „Cofnij” po usunięciu.
4. **Nic nie jest nieodwracalne.** Usuwanie idzie do kosza systemowego, zmiany w edytorze mają
   cofanie, a „usuń projekt” zdejmuje go tylko z listy (pliki zostają).
5. **Klawiatura i mysz na równi.** Wszystko, co jest pod ikoną, jest też komendą w palecie (⌘⇧P)
   i można mu przypisać skrót.
6. **Puste stany to obrazki.** Pusty projekt pokazuje piktogram „upuść tu pliki”, a brak PDF
   piktogram kartki z kołem zębatym i skrótem ⌘S.

## 2. Ekran startowy: projekty

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [logo] praTexEditOR                                 [⌕ szukaj]  [⚙]          │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐                         │
│  │ ░░░░░░░ │  │ ░░░░░░░ │  │ ░░░░░░░ │  │         │                         │
│  │ ░ PDF ░ │  │ ░ PDF ░ │  │ ░ PDF ░ │  │   [+]   │  ← nowy projekt          │
│  │ ░░░░░░░ │  │ ░░░░░░░ │  │ ░░░░░░░ │  │         │                         │
│  ├─────────┤  ├─────────┤  ├─────────┤  └─────────┘                         │
│  │● Praca  │  │● Raport │  │● Artykuł│   ● = kolor projektu                  │
│  │[▢]2 2 d │  │[▢]1 dziś│  │[▢]3 5 d │   [▢]n = liczba folderów, wiek        │
│  └─────────┘  └─────────┘  └─────────┘                                       │
└──────────────────────────────────────────────────────────────────────────────┘
```

- Karta = miniatura 1. strony ostatniego PDF + nazwa + kolorowa kropka. Klik otwiera projekt.
  PPM otwiera menu z ikonami: zmień nazwę, kolor, eksport `.zip`, usuń z listy.
- Kolejność: ostatnio otwierane. `⌕` filtruje na żywo. ⌘1…⌘9 otwiera n-tą kartę.
- Upuszczenie folderu z Findera na ekran startowy tworzy z niego projekt.

**Kreator `[+]`:** trzy duże kafle z piktogramami.

```
   ┌──────────┐   ┌──────────┐   ┌──────────┐
   │  [▦▦]    │   │  [▢→]    │   │  [⧉zip]  │
   │ Szablon  │   │  Folder  │   │   ZIP    │
   └──────────┘   └──────────┘   └──────────┘
```
- **Szablon:** siatka miniatur (raport, artykuł, praca dyplomowa, beamer, własne), potem nazwa
  i miejsce na dysku (domyślnie ostatnio używane), Enter.
- **Folder:** systemowy wybór folderu. Plik główny wykrywany sam; jeśli kandydatów jest kilka,
  pokazujemy listę z miniaturami pierwszych linii.
- **ZIP:** np. eksport z Overleaf, rozpakowany do wskazanego folderu.

## 3. Widok projektu: trzy kolumny

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ [logo] (● Praca ▾)  [▤ Projekt] [▣ Tablica] [✎ Notatki] [⚙]      [◧][▯][◨]  [?]     │
├──────────────┬───────────────────────────────────────┬───────────────────────────────┤
│ DRZEWO       │ [main.tex ×][wstep.tex ●×][bib ×]      │ (● gotowe 1,2 s)        [⋯]   │
│ [+▢][+▣][⇵]  │ Rozdział 2 › 2.3 Metody ▾        412 sł│ [−] 110 % [+] [↔][▭] [◎][☾] [⤓]│
│ ▾ ● praca/   │ [B][I][U] │[H▾][•][1.]│[Σ▾][▣][▦]│[↗ref][❝cite]                         │
│   ★ main.tex │───────────────────────────────────────│ ┌───────────────────────────┐ │
│   ▸ rozdz/   │  12  \section{Metody}                 │ │                           │ │
│   ▸ img/     │  13  Badania przeprowadzono na ...    │ │        strona 4           │ │
│     bib.bib  │  14  \begin{figure}[h]                │ │                           │ │
│ ▾ ● dane/    │ ⚠15    \includegraphics{img/wyk.png}  │ │      ┌ ─ ─ ─ ─ ┐ ← SyncTeX │ │
│     wyk.csv  │  16  \end{figure}                     │ │                           │ │
│              │                                       │ └───────────────────────────┘ │
│              │                                       │ ┌ szuflada błędów (zwinięta)┐ │
└──────────────┴───────────────────────────────────────┴───────────────────────────────┘
```

- Pasek górny jak w praSzczur: chip projektu (klik pokazuje listę projektów i „wszystkie
  projekty”), zakładki z ikoną i krótką nazwą. Po prawej trzy ikony **pokaż/ukryj kolumnę**
  `[◧][▯][◨]` (⌘⌥1/2/3) i `[?]` (okno skrótów).
- **Splity** przeciągane, podwójny klik przywraca domyślną szerokość, a przeciągnięcie do krawędzi
  zwija kolumnę (zostaje cienki pasek z ikoną). Wszystko zapamiętywane per projekt (`wsSet`).
- **Tryb skupienia** ⌘⇧Enter: tylko edytor i PDF, bez paska górnego.

### 3.1 Drzewo (lewa kolumna: tylko pliki)
- Nagłówek: `[+▢]` nowy plik, `[+▣]` nowy folder, `[⇵]` zwiń wszystko, `[⌕]` filtr nazw.
- Root = kolorowa kropka + nazwa folderu. `[+]` przy nagłówku (lub upuszczenie folderu
  z Findera na puste miejsce) podpina kolejny folder do projektu.
- Ikony typów: `.tex`, `.bib`, obraz, PDF, dane (`.csv`), inne. ★ = plik główny.
  Plik z błędami kompilacji ma małą czerwoną kropkę, a otwarty i niezapisany ma kropkę akcentu.
- Najechanie na obraz pokazuje miniaturę w dymku po 300 ms.
- Podwójny klik / Enter otwiera plik w karcie, a pojedynczy klik otwiera podgląd (karta
  kursywą, zastępowana przy następnym podglądzie), jak w VS Code.
- Obraz lub PDF otwarty z drzewa wyświetla się w środkowej kolumnie jako podgląd.
- PPM: menu z ikonami (nowy, zmień nazwę, duplikuj, ustaw jako główny, kopiuj ścieżkę
  względną, pokaż w Finderze, do kosza).
- **DnD:** przeciągnięcie pliku na folder przenosi go (z ⌥ kopiuje). Folder pod kursorem
  świeci, a po 600 ms zawisu się rozwija. Przeniesienie `.tex`/obrazu pokazuje pasek
  „Zaktualizować N odwołań?” `[✓] [✕]`.

### 3.2 Edytor (środek)
- **Karty:** kropka = niezapisane (autozapis i tak zapisze po chwili), ⌘W zamyka, środkowy klik
  zamyka, przeciąganie zmienia kolejność.
- **Okruszki (outline, lekki):** `Rozdział 2 › 2.3 Metody ▾`. Pokazują, gdzie w dokumencie jest
  kursor. Klik w człon rozwija listę sekcji na tym poziomie, a wybór przenosi tam (także do
  innego pliku). Po prawej licznik słów (klik pokazuje dymek: słowa, znaki, cały dokument
  i zaznaczenie).
- **Pasek „Wstaw”** (ikony w grupach, zwijany ⌘⇧I):
  `[B][I][U]` tekst │ `[H▾]` sekcje (część…akapit) · `[•]` lista · `[1.]` numerowana │
  `[Σ▾]` matematyka (inline, equation, align) · `[▣]` rysunek · `[▦]` tabela │ `[↗]` ref · `[❝]` cite.
  Każda ikona = snippet. Z zaznaczeniem owija tekst, bez zaznaczenia wstawia szkielet z kursorem
  w pierwszym polu (Tab przechodzi dalej).
- **Znaczniki błędów** na marginesie (czerwony/żółty). Najechanie pokazuje komunikat z logu.
  F8 / ⇧F8 przechodzi do następnego / poprzedniego.

### 3.3 PDF (prawa kolumna)
- **Pigułka statusu** (zawsze w tym samym miejscu, jedyny „tekst” paska):
  `● gotowe 1,2 s` (zielona) · `⟳ kompiluję` (akcent, pulsuje) · `☁ pobieranie pakietów 34 %`
  · `✕ 2  ⚠ 5` (czerwona, liczby z ikonami). Klik rozwija szufladę błędów. ⌘S / ⌘Enter
  wymusza kompilację, a ikona `[▶|⏸]` w pigułce włącza/wyłącza auto-kompilację dla projektu.
- Pasek: zoom `[−] 110 % [+]`, `[↔]` dopasuj szerokość, `[▭]` stronę, `[◎]` podążaj za kursorem,
  `[☾]` ciemny PDF (E8), `[⤓]` eksportuj PDF (obok pliku głównego lub „Zapisz jako”),
  `[⋯]` więcej (otwórz w Podglądzie, kopiuj stronę jako obraz, zrzut fragmentu → Tablica).
- **SyncTeX:** klik w PDF (ustawienie: klik / ⌘+klik) przenosi do kodu i podświetla linię.
  ⌘+klik w kodzie lub ⌘J przewija PDF do miejsca i rysuje pulsującą ramkę.
  `[◎]` robi to samo co ⌘J, a ikona łańcucha `[⊸]` włącza „podążaj za kursorem”. Dodatkowy kursor
  w edytorze: ⌥+klik.
- Numer strony w rogu przy przewijaniu (znika po 1 s), ⌘G = idź do strony.

## 4. Gdzie są outline, błędy, bibliografia i obrazy (nie w drzewie)

| Funkcja | Miejsce | Dlaczego tam |
|---|---|---|
| **Outline** | okruszki nad edytorem + **⌘⇧O** (lista sekcji z wcięciami, filtr na żywo) | pokazuje kontekst tam, gdzie piszę; pełna lista na żądanie |
| **Błędy i ostrzeżenia** | pigułka w PDF + **szuflada** wysuwana z dołu kolumny PDF + znaczniki w edytorze | błąd dotyczy PDF-u, który właśnie nie powstał; prowadzi prosto do linii |
| **Bibliografia** | podpowiedź `\cite{` (karty: autor, rok, tytuł) + ikona `[❝]` otwiera **modal Biblioteka** (⌘⇧B: wyszukiwarka, wstaw zaznaczone, otwórz w `.bib`) | bibliografię się wstawia, a nie przegląda |
| **Obrazy** | podpowiedź `\includegraphics{` z miniaturami + dymek z podglądem po najechaniu na ścieżkę w kodzie + ikona `[▣]` otwiera **galerię** obrazów projektu (siatka miniatur, klik = wstaw) | obraz wybiera się wzrokiem |

**Szuflada błędów:**
```
│ [✕ 2][⚠ 5][▭ 12]              [⧉ surowy log] [⌄] │   ← filtry-ikony (włącz/wyłącz)
│ ✕ main.tex:15   Undefined control sequence  \inclugraphics │
│ ✕ rozdz/2.tex:40  Missing $ inserted                       │
│ ⚠ main.tex:3    Citation 'kowalski2020' undefined          │
```
Klik w wiersz otwiera plik na tej linii. `▭` = overfull/underfull box (domyślnie wyłączone).
Przy znanych błędach jest krótka podpowiedź (np. „literówka? `\includegraphics`”).

## 5. Snippety i podpowiedzi

- Wpisanie `\` otwiera listę komend z ikonami rodzaju: `ƒ` komenda, `▢` środowisko,
  `⚡` snippet, `#` etykieta, `❝` cytowanie, `▣` plik. Obok zaznaczonej pozycji jest podgląd
  tego, co się wstawi (dla snippetów cały szkielet z zaznaczonymi polami).
- Prefiksy snippetów bez `\`: `fig` + Tab = rysunek, `tab`, `eq`, `ali`, `itm`, `enu`, `sec`, `frm`
  (frame). Pełna lista: okno `?`, zakładka Snippety.
- `\begin{` podpowiada środowiska, a po wyborze wstawia `\end{…}` i ustawia kursor w środku.
- Pola snippetu (`$1`, `$2`) mają ramkę akcentu, Tab / ⇧Tab przeskakuje, Esc kończy.
- Matematyka: `$` wstawia parę `$$` z kursorem w środku. Zaznaczenie + `$` owija tekst.

## 6. Wklejanie i przeciąganie obrazów

**⌘V ze zrzutem w schowku** (lub upuszczenie pliku obrazu na edytor):
```
┌──────────────────────────────────────────────────┐
│  ┌────────┐   nazwa: [ wykres-2026-10-23-1412 ]  │
│  │ minia- │   folder: [▣ img/ ▾]                 │
│  │ tura   │   [▣ sam obraz] [▦ rysunek+podpis]   │  ← dwa kafle-ikony, zapamiętany wybór
│  └────────┘                    [↵ Wstaw]  [Esc]  │
│  [□] nie pytaj, używaj tych ustawień              │
└──────────────────────────────────────────────────┘
```
- Nazwa podpowiadana i zaznaczona, więc wystarczy pisać albo od razu wcisnąć Enter.
- Folder domyślny: `imgDir` projektu (pierwszy raz pyta, później pamięta). Ścieżka w kodzie
  jest liczona względem pliku głównego.
- „Rysunek + podpis” wstawia `figure` z kursorem w `\caption{}`, a `\label{fig:<nazwa>}`
  powstaje automatycznie.
- Z zaznaczonym „nie pytaj” ⌘V wstawia od razu i pokazuje toast `[✎ zmień nazwę] [↶ cofnij]`.
- Upuszczenie pliku z Findera na **drzewo** kopiuje go do folderu (bez wstawiania kodu), a na
  **edytor** kopiuje do `imgDir` i wstawia kod w miejscu upuszczenia (kursor-duch pokazuje gdzie).
  Pliki `.tex` upuszczone na edytor wstawiają `\input{…}`.

## 7. Ustawienia

Lewa lista sekcji z ikonami: **Ogólne · Edytor · Kompilacja · PDF · Skróty · Snippety ·
Projekty · O aplikacji**. Zmiana zapisuje się natychmiast (bez „Zapisz”). Przy każdej
zmienionej wartości jest ikona `↺` przywracająca domyślną.

**Skróty:**
```
│ [⌕ filtr: nazwa albo naciśnij skrót]                         [⇩ import VS Code] │
│ [B]  Pogrubienie              ⌘B        edytor        ↺                          │
│ [▣]  Wstaw rysunek            ⌘⇧F       edytor                                   │
│ [⚡]  Snippet: tabela 3×3      —  [+]                                             │
│ [⌘]  Paleta komend            ⌘⇧P       wszędzie                                 │
```
- Klik w skrót włącza nagrywanie („naciśnij klawisze…”, pulsuje). Akord nagrywa się drugim
  naciśnięciem w ciągu 1 s.
- **Kolizja** pokazuje chip `koliduje z: Wstaw rysunek` `[⇄ zamień] [✕ anuluj]`.
- Filtr działa też „po klawiszu”: naciśnij ⌘B w polu filtra, a zobaczysz, co jest pod tym skrótem.

**Snippety:** lista po lewej (grupy, ikony), edytor po prawej: `prefiks`, `skrót`, `ikona`
(wybór z siatki), treść z podświetleniem `$1`. Pod spodem **podgląd na żywo**, jak snippet się
wstawi. „Pokaż na pasku Wstaw” to przełącznik. Import `.json` z VS Code.

**Kompilacja:** auto-kompilacja (przełącznik + opóźnienie), silnik domyślny (Tectonic / latexmk
+ pdfLaTeX / XeLaTeX / LuaLaTeX, wykryte instalacje z wersją), cache Tectonic (rozmiar,
wyczyść), „kopiuj PDF obok pliku głównego po kompilacji”.

## 8. Szybka nawigacja

| Skrót | Okno | Co pokazuje |
|---|---|---|
| ⌘P | Szybkie otwieranie | pliki projektu (fuzzy, ikony typów, ostatnie na górze) |
| ⌘⇧P | Paleta komend | wszystkie komendy z ikoną i skrótem; prefiks `>` |
| ⌘⇧O | Sekcje | outline całego dokumentu; prefiks `@` |
| ⌘T | Etykiety | `\label` w projekcie; prefiks `#` |
| ⌘⇧B | Biblioteka | pozycje `.bib` |

Jedno okno, przełączane prefiksem (jak w VS Code): wpisanie `>` w ⌘P przełącza na komendy.

## 9. Notatki, Tablica, notatnik pływający

- **Notatki** (zakładka): lista + edytor Markdown, globalne (jak w praSzczur). ⌘+klik na tekście
  w PDF lub zaznaczenie w edytorze + ⌘⇧N dopisuje fragment do przypiętej notatki
  (z odnośnikiem `plik:linia`).
- **Notatnik pływający:** ⌘⇧M, okno przeciągane nad wszystkim, pamięta pozycję.
- **Tablica** (zakładka, ładowana leniwie): płótno jak w praTRD. `[⋯] → zrzut fragmentu`
  w PDF zaznacza prostokąt, który trafia na ostatnio otwartą tablicę z podpisem `plik.pdf s. 4`.

## 10. Domyślne skróty (macOS; na Win/Linux ⌘ → Ctrl)

| Skrót | Akcja | | Skrót | Akcja |
|---|---|---|---|---|
| ⌘S / ⌘Enter | zapisz + kompiluj teraz | | ⌘B / ⌘I / ⌘U | pogrubienie / kursywa / podkreślenie |
| ⌘. | przerwij kompilację | | ⌘⇧F | wstaw rysunek |
| ⌘J | pokaż w PDF (SyncTeX) | | ⌘⇧T | wstaw tabelę |
| ⌘⇧P / ⌘P | paleta / szybkie otwieranie | | ⌘E / ⌘⇧M | `$…$` / notatnik |
| ⌘⇧O / ⌘T | sekcje / etykiety | | ⌘/ | zakomentuj `%` |
| F8 / ⇧F8 | następny / poprzedni błąd | | ⌘D | zaznacz następne wystąpienie |
| ⌘⌥1/2/3 | pokaż/ukryj kolumnę | | ⌘⇧Enter | tryb skupienia |
| ⌘± / ⌘0 | zoom PDF / dopasuj | | ? (poza edytorem) | okno skrótów |

kursor w edytorze: ⌥+klik (⌘+klik = SyncTeX).

## 11. Ruch i stany
- Przejścia 0,15 s, wejście widoku `fadein 0,35 s`, boot screen z logo jak w praSzczur.
- Pierwsza kompilacja projektu: w kolumnie PDF szkielet strony z animowanym połyskiem zamiast
  pustki.
- Długie operacje (rozpakowanie ZIP, aktualizacja odwołań, pobieranie pakietów) zawsze mają
  `ProgressRing` / `LoadingBar` i da się je anulować.
